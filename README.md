# Cosmetic-ingredients-compability
Курсовая работа на тему "Математический аппарат автоматизированной системы для контроля совместимости ингредиентов в косметике"

## Наименование файлов и их предназначение:
- classes.h – заголовочный файл, содержащий основные классы;
- db_function.cpp – функции для работы с базами данных (считывание информации, обработка, хранение и запись в файл);
- db_function.h – заголовочный файл с объявлением функций db_function.cpp;
- db_relations.cpp – файл построения базы данных связей на основеимеющихся данных;
- main.cpp – основная часть программы, реализующая логику анализа совместимости в введённом(ых) пользователем списке(ах).

## В качестве имитационных баз данных представляются файлы:
- ingredients.txt – файл с информацией об ингредиентах;
- category.txt – файл с информацией о видах;
- conflict.txt – файл с информацией о конфликтах видов;
- relation.txt – файл с информацией о совместимости парингредиентов;
- check_and_insert_in_db.txt – файл с неизвестными наименованиями, необходимый для их (наименований) дальнейшей проверки;
